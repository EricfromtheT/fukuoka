太宰府天滿宮故事與參拜禮節

01這座神社在祭誰

太宰府天滿宮祭的是平安時代的學者、詩人、政治家菅原道真（845–903）。他學問好、詩也寫得好，一度做到朝廷高官「右大臣」。

日本各地有許多天滿宮，福岡這座是總本社之一，而且就建在他長眠的地方。

02從京都被貶到太宰府

道真深受天皇信任，卻被當時掌權的藤原家當成威脅。他們誣告他，在 901 年把他從京都流放到九州的太宰府。

到了這裡，他被剝去官職與財產，過得很苦，卻始終沒有怨恨天皇。903 年，他在太宰府過世，享年 59 歲。追隨他的門人把遺體葬在這裡，並蓋了一座小小的祠——這就是天滿宮的起點。

03過世之後，被奉為天神

道真死後，京都接連發生雷擊、災異，朝野認為是他的怨靈作祟。後來朝廷為他平反，並把他奉為「天滿天神」——學問、文化與藝術之神。

從門人的小祠開始，一千一百多年後，這裡成為日本最重要的天神信仰聖地之一。現在看到的本殿，是 1591 年重建的，已被指定為重要文化財。

04飛梅的傳說

道真最愛梅花。被貶離開京都時，他寫詩向庭中的梅樹告別，大意是：東風啊，把花香吹過來吧；即使主人不在，也別忘了春天。

傳說那棵梅樹不忍分離，連夜拔根飛到太宰府與他相會。本殿右側那棵「飛梅」，就是這段故事的象徵。境內約有六千棵梅樹，梅花也成了天滿宮的標記。

05為什麼考生都來這裡

因為主祭的是學問之神，考試季常有學生來求合格、升學順利，會在繪馬上寫願望。一般遊客來參拜，求的多半也是學業、才藝，或一份安心。

06走過鳥居的方式

鳥居是人間與神域的分界，像進長輩家門口：先鞠躬，再走進去。正中央是神明走的路，人靠左或靠右過，不要走中間。

  1. 走到鳥居前，面向社殿方向輕輕一鞠躬。
  2. 靠邊穿過鳥居。走右側就先出右腳，走左側就先出左腳。
  3. 過了鳥居，參道也一樣靠邊走，把中間留給神明。
  4. 離開時穿過鳥居後，轉身面向社殿再鞠躬一次，再走回參道。

07參拜流程：手水 → 本殿

太宰府的動線大致是：參道 → 鳥居 → 心字池／太鼓橋 → 手水舍 → 樓門 → 御本殿。過太鼓橋後，手水舍在右手邊。參拜前先在這裡洗手漱口，再去本殿。

手水（一杓水做完）

  1. 右手拿杓舀水，沖左手。
  2. 換左手拿杓，沖右手。
  3. 再換回右手拿杓，把水倒在左手掌心，用掌心的水漱口——嘴巴不要碰杓。
  4. 再沖一次左手。
  5. 把杓豎起來，讓剩下的水順柄流下，洗掉握過的地方，再放回原位。

本殿前：二拜二拍手一拜

  1. 在賽錢箱前站好，輕輕投入賽錢。有鈴就先輕搖一下。
  2. 深深鞠躬兩次（上半身明顯前傾，不是點頭）。
  3. 雙手在胸前合起，右手略往後抽一點，與肩同寬拍手兩次。
  4. 雙手合十，默禱幾秒。
  5. 放下手，再深深鞠躬一次，然後往旁邊讓開，不要擋後面的人。

賽錢沒有規定金額；有人投 5 日圓，因為發音像「ご縁」（好緣分）。心意到就好。境內不要大聲喧嘩，御神牛可以摸、不要騎。

到現場可以留意

參道先逛再進神社。過鳥居先鞠躬、靠邊走。心字池三座太鼓橋象徵過去、現在、未來。本殿右側找飛梅。參道梅枝餅可邊走邊買帶回程。
